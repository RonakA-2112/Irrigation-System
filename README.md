# Irrigation-System
This is a project aimed at preserving garden plants over long periods of no human interaction where the system powers a pump that waters the plant after taking in data such as current weather and soil moisture.

I noticed an issue whenever my family left for vacation. The plants would die due to the lack of water, so I decided to develope an automated irrigation system that waters the plants based on soil moistrue and current weather as well as outputting it on ThinkSpeak where we can monitor it constantly.
